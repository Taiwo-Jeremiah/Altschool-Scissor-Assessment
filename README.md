# Scissor

A static landing page concept for Scissor, a URL-shortening and link-management service. The page is built with HTML and CSS and uses local SVG graphics and Gilroy font files.

## Page sections

- Hero and navigation
- Service statistics and feature highlights
- Pricing plans
- URL-shortening form mockup
- FAQ accordion
- Call-to-action banner and footer

## View locally

No package installation or build step is required. Open `index.html` in a browser, or serve the project directory locally:

```powershell
py -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

Check it out live here (https://taiwo-jeremiah.github.io/Altschool-Scissor-Assessment/)

## Project files

- `index.html` — page structure and content
- `styles.css` — layout, colors, and typography
- `assets/images/` — SVG logos, illustrations, and icons
- `assets/fonts/` — Gilroy font files

## Notes

This is a front-end mockup only. The URL form does not create shortened links, and navigation, pricing, and call-to-action links are placeholders. No backend or JavaScript functionality is included.
